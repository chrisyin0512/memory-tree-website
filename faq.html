FAQ

Frequently asked questions

What is Memory Tree?

Memory Tree is a private family journal for organizing memories by year across personal, shared, and managed timelines.

Do I need an account?

Yes. Memory Tree uses accounts so your timelines can sync securely and shared timelines can work across family members.

Can I create timelines for family members?

Yes. You can create managed timelines for children, parents, grandparents, or other loved ones. Managed timelines can be kept private or shared.

What can I add to a memory?

You can add bullet points, photos, voice notes, essays, and AI-organized memories by year.

How does AI work in Memory Tree?

AI can help search your timelines, transcribe voice recordings, and organize spoken memories into year cards. You should review AI output before saving it.

Does Memory Tree support Chinese and English?

Yes. Memory Tree supports English and Simplified Chinese. AI search and transcription are designed to work with English, Chinese, and mixed-language memories.

Can I export my timeline?

Yes. Memory Tree includes PDF export so you can keep or print a clean copy of a timeline.

How do I contact support?

Email support@memory-tree.app and include the email address used for your Memory Tree account.
